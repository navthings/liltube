# liltube

youtube without the algorithm. just new uploads from channels i actually like.

live at [navthings.github.io/liltube](https://navthings.github.io/liltube)

- no shorts, no recommendations, no comments
- sponsor reads skipped automatically (sponsorblock)
- picks up where you left off, continue watching row
- save for later, surprise me, playback speed
- history builds up over time, not just the last 15 uploads
- add to home screen on your phone and it opens like an app

rebuilds every 3 hours. add channels in `CHANNELS` at the top of `liltube.py`.

run it locally:

```
python3 liltube.py
```
