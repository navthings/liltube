# liltube

youtube without the algorithm. just new uploads from channels i actually like, no shorts, no recommendations.

live at [navthings.github.io/liltube](https://navthings.github.io/liltube)

rebuilds every 3 hours. add channels in `CHANNELS` at the top of `liltube.py`.

run it locally:

```
python3 liltube.py
```
